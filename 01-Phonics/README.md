## วิธีใช้
1. อ่าน "อธิบายเป็นภาษาไทย" ให้เข้าใจก่อน
2. ดู "ตัวอย่าง" ประกอบทุกครั้ง ออกเสียงดัง ๆ
3. อ่าน "เทคนิคจำ" และ "ข้อผิดพลาดที่เด็กไทยพบบ่อย" ก่อนลงมือทำแบบฝึกหัด
   (จะช่วยไม่ให้พลาดจุดที่คนไทยมักผิด)
4. ทำ "แบบฝึกหัด" ให้ครบก่อนเปิด "เฉลย"
5. ผ่านหัวข้อนี้แล้วค่อยไปหัวข้อถัดไป
