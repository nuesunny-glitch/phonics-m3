## How to insert a real image later

Each placeholder `<figure>`/`<div>` carries a `data-illus-asset="…"`
attribute naming its planned file. To swap in real art:

1. Export the final image as WebP at 2x the container's rendered size
   (hero/topic cards render ~4:3 at up to ~700px wide → export
   ~1400×1050px; vocab cards are square ~92px → export ~200×200px).
2. Drop the file into `01-Phonics/assets/illustrations/`.
3. Replace the placeholder's inner `<span class="illus-ph-icon">…`
   block with:
   ```html
   <img src="../assets/illustrations/FILENAME.webp" alt="ALT TEXT FROM aria-label"
        width="800" height="600" loading="lazy" style="width:100%;height:100%;object-fit:cover;">
   ```
   (`loading="lazy"` for every asset except the hero — the hero is
   above the fold on page load, so it should stay eager: omit
   `loading="lazy"` only on `lesson1-phonics-hero.webp`.)
4. Re-run `01-Phonics/_tools/build.sh` if editing the `_tools/body-*`
   source files (the canonical source — see below), not the generated
   `NN-Topic/lesson.html` output directly.

## Editing note (source-of-truth)

`01-Phonics/` is generated by `_tools/build.sh` from `_tools/body-NN-*.html`
fragments. All illustration markup above was added to the **source**
fragments (`body-01-lesson.html`, `body-02-lesson.html`,

re-run to regenerate the actual `NN-Topic/lesson.html` output files —
edit the source, not the generated output, or a future rebuild will
silently discard direct edits to the output.
